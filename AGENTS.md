# Autonomous Execution Guidelines

1. **Full Autonomous Operation**:
   - The user has granted full permissions to execute terminal commands, edit/create files, run builds, invoke MCP tools, and test application components.
   - Do NOT ask for permission or confirmation before taking action (e.g. "May I proceed?", "Should I run this?", etc.).
   - Do NOT block execution with interactive prompt modals unless explicitly requested by the user.
   - Take full initiative to inspect, edit, build, run, and verify tasks end-to-end autonomously.

2. **Action & Verification**:
   - Proactively fix issues, run builds, test outputs, and report concise, clear summaries upon completion.
